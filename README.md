# Birthday invite

A small, responsive birthday invitation page in Russian. It is a static site: the answer buttons show a response on the page, but **do not send the answer to the host**.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
This repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment → Source**, select **GitHub Actions**.
3. Open the **Actions** tab and wait for **Deploy static site to GitHub Pages** to finish successfully.
4. The published URL will appear in the workflow run and in **Settings → Pages**. It should look like `https://akocarev455-jpg.github.io/birthday-invite/`.

No name, date, or location is included. Edit `index.html` if you want to customize the text.
